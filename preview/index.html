What is real and what is simulated

Every image below is a screenshot of the actual app binary, built by GitHub Actions on a macOS runner and launched in the iOS Simulator. Nothing here is an HTML mockup.

AspectStatusNotes
Visual design Native Real SwiftUI render. Layout, spacing, type and colour are the app's own.
Navigation between screens Native The tab bar and the Pro workspace entries below push real NavigationStack routes.
Scrolling a screen Simulated The capture is a static image. Scrolling here moves the image, not app state.
Typing, search, filters, booking Not available These need a live binary. They are implemented in the app but cannot be exercised from this page.
Content Fixtures Illustrative figures. The app shows a banner on Home while it runs against them.
Physical-device behaviour Unverified No iPhone or iPad has run this. Real-device checks such as Dynamic Type, safe areas and haptics are untested.

Why screenshots and not a web rebuild

A hand-written HTML version of these screens would look identical today and silently diverge from the SwiftUI source within a week. Serving captured output from the real build makes that impossible. The preview regenerates on every push to main, from the same commit as the app.
